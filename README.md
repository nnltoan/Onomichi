# ONOMICHI – demo restaurant site

A fictional six-seat Japanese bowl counter in Helsinki, made as a demo for beestaff.ai (videos, sales demos, screen recordings).
Name, address, phone, email and menu are invented. Do not present it as a real business.

- Single static page: `index.html` (EN, FI toggle) + `images/`.
- Replace `images/hero.svg` with your own photo (own shot or AI-generated, no real people, no third-party photos).
- Hosting: GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
